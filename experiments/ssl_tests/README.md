### Visualization of the SSL attentions and feature maps
It supports options: DINOv2, DINOv2-reg, CLIP, MAE, DeiT-III

The code is based on the Fit3D repository (TODO: add the link)

### Installation
This command will create a conda environment with all the dependencies.
```bash
conda env create -f environment.yml
conda activate ssl_tests
```


Current running command:
```bash
python ssl_visualization.py
```
